Live assistant layout

Three panels tuned for calls that are happening now

During a live meeting, Echo mirrors how you actually work: follow the transcript as it grows, skim keywords and web hits beside the conversation, then ask the chat strip for a precise answer grounded in what people just said—without juggling another heavyweight meeting tab.

Transcript stays primary—even when the meeting is live

In live mode, new lines appear as the meeting unfolds so you are never rereading a static wall of text. Demo, replay, and saved-audio paths are there when you want to rehearse or debrief, but the layout is built around a transcript that keeps moving like the call itself.

Live meeting audio, end to end

For live meetings, Echo listens to both sides of the conversation: your microphone and the audio the call plays into your headset or speakers. On macOS you can choose a simpler capture path that pulls system output alongside your voice so remote attendees stay in the same transcript you hear.

Why use Echo

A focused live meeting assistant, not another SaaS

▣

Live meetings first

The headline experience is the call you are in right now: capture audio as it happens, keep the transcript moving, and let insights and chat stay tied to the same thread. Demo, replay, and saved-audio modes remain for rehearsal, coaching, or offline review.

⌕

Web context on a cadence

Periodic search pulls in fresh articles, definitions, and public facts beside the meeting so you are not copy-pasting queries mid-call.

✦

Optional AI summaries

Turn on short AI-generated highlights when you want them—keyword nudges, tight recaps, and richer answers in chat when you bring your own provider.

⎘

Keyboard-first workspace

Jump between transcript, insights, and chat without reaching for the mouse—built for people who live in focused, text-forward environments.

◆

Quick connectivity check

A lightweight command exercises the same search and AI paths as the assistant so you can confirm everything is reachable before an important call.

◇

Open for teams who build

Fork, customize, and share improvements freely—ideal for experimentation, internal pilots, and teaching assistants in your own stack.

Your data stays yours

Echo is not a hosted meeting cloud: transcripts stay on the machine you run, web lookups only fire when you enable them, and AI features stay off until you choose to connect a provider you trust.

Meeting audio stays local unless you deliberately send it to a transcription or AI service you configure. For stricter rooms, read the project README for offline-friendly and timeout controls before going live.

Developers & curious operators

Clone, install, run

git clone https://github.com/McK-Playground/prj-echo.git
cd prj-echo
python3 -m venv .venv
source .venv/bin/activate
pip install -e .

# Optional speech-to-text + live capture
pip install -e ".[asr]"

echo-tui
echo-tui --replay samples/sample_transcript.txt --line-delay 0.8

Remember to launch echo-tui (or python -m echo); the shell builtin echo only prints arguments. Full flags, environment variables, and macOS audio notes live in the README on GitHub.
